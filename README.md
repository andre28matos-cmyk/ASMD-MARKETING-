# ASMD-MARKETING-
Crie um bot com IA para a ASMD, integrado ao WhatsApp Business. O bot deve conversar naturalmente, apresentar serviços, coletar dados dos clientes, preparar orçamentos, agendar reuniões e encaminhar atendimentos para André, Vinícius ou Mateus, com segurança e atendimento automatizado 24 horas.
